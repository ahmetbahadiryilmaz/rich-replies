# Contributing

Source lives in `hooks/register.tsx` (the mod) with tests next to it (`hooks/*.test.tsx`). Code comments and some identifiers are in Turkish; behaviour and user-facing syntax are documented in the README.

## Run the tests

```bash
claude plugin test .
```

## Type-check

The type declarations for the `claude-code` module are generated by Claude Code itself into `.claude-plugin/types/` (git-ignored, never committed), so a fresh clone cannot be type-checked until they exist. Load the repository once as a dev mod in Claude Code so that folder is generated, then run:

```bash
npx -p typescript tsc -p . --noEmit
```

`types/index.d.ts` is the mod's own state declaration and is committed.

## Icon

`python tools/make_icon.py` regenerates `icon.png` (needs Pillow).

## Validate the manifest

```bash
claude plugin validate . --strict --profile directory
```
